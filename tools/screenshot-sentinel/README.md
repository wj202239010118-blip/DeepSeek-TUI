# 飞书截图哨兵（路径自动入剪贴板）

这个小工具用来解决一个问题：你在飞书里截图后，剪贴板里通常是“图片本身”。如果你想把图片作为文件路径引用到 Claude / Trae / VS Code / README 里，就需要把它落盘并拿到路径。

本工具会在你截图后自动：
- 把截图保存到本地文件夹
- 把“图片路径”写入剪贴板（你直接 Ctrl+V 粘贴的就是路径）
- 自动清理旧文件（只保留最近 N 张）

## 1. 目录里有哪些文件

- `feishu_screenshot_guard.py`：核心脚本（推荐用它）
- `requirements.txt`：Python 依赖
- `开始监控.bat`：启动入口（有窗口、有日志，方便排查）

## 2. 第一次使用（安装）

1) 安装 Python（Windows 建议 3.9+）。安装时勾选 “Add Python to PATH”（加入环境变量）。

2) 安装依赖：在本目录空白处右键 → “在终端中打开”，执行：

```bash
pip install -r requirements.txt
```

## 3. 启动方式（推荐）

双击运行 `开始监控.bat`。

## 4. 正常工作流程（你每天怎么用）

1) 先启动哨兵（双击 `开始监控.bat`）。

2) 在飞书里按 `Ctrl + Shift + A` 进行截图，正常选区域并确认。

3) 截图完成后：
- 你会在保存目录里看到新增的图片文件
- 你的剪贴板会被替换成“图片路径”

4) 去任何地方 Ctrl+V：
- 在 Claude / Trae / 终端里粘贴：得到路径字符串
- 在 Markdown / README 里粘贴：可直接引用这张图的本地路径（或你再手动改成相对路径）

## 5. 怎么停止（重要）

有 2 种停止方式，按“简单程度”排序：

1) 关闭黑色窗口：点窗口右上角 `X`
2) 在黑色窗口里终止程序：先点一下黑色窗口让它获得焦点，然后按住 Ctrl 不放，再按 C  
   - 这里的 Ctrl+C 是“终止正在运行的程序”，不是复制

停止后会发生什么：
- 哨兵不再保存截图、不再改写剪贴板
- 飞书截图恢复原生行为（剪贴板只进图，不会自动变成路径）

## 6. 保存位置与自动清理

默认保存目录：
- `feishu_uploads`（在脚本所在目录下自动创建）

默认保留数量：
- 只保留最近 `5` 张（更旧的会被物理删除）

## 7. 常用参数（可选）

你可以在命令行运行脚本并传参数。

### 指定保存目录与保留数量

```bash
python feishu_screenshot_guard.py --dir "D:\Work\Claude_Uploads" --max 10
```

### 调整“等待截图完成”的策略

工具是“状态机模式”：
- 你按一次热键 → 进入待命（轮询剪贴板等待新图片）
- 检测到新图片 → 保存并回写路径 → 退出待命
- 待命期间如果你再次按热键，会重置计时（不假死）

参数：
- `--timeout`：待命最长秒数（默认 15）
- `--poll`：轮询间隔秒数（默认 0.25）
- `--delay`：按热键后先等一小会再开始待命（默认 0.5）

示例：

```bash
python feishu_screenshot_guard.py --timeout 20 --poll 0.2 --delay 0.4
```

### 路径输出格式

- `--path absolute|relative`：写回剪贴板是绝对路径还是相对路径（默认 absolute）
- `--style win|posix|native`：路径分隔符风格
  - `win`：`D:\a\b\c.png`
  - `posix`：`D:/a/b/c.png`
  - `native`：按系统自动选择

示例：

```bash
python feishu_screenshot_guard.py --path absolute --style win
```

## 8. 常见问题（排查）

### 8.1 截图后没反应

先用调试模式启动：
- 双击 `开始监控.bat`

然后再截图，看窗口里是否提示：
- “待命：等待新截图进入剪贴板”：说明热键触发正常
- “超时：未检测到新截图”：可能截图被取消，或飞书没把图片放进剪贴板

如果你是“弹出一堆乱码然后闪退”：
- 这是 Windows 批处理文件编码/控制台编码导致的常见现象。本项目的 .bat 已尽量只输出英文并强制切到 UTF-8，但如果你改过 .bat 内容并加入中文，建议用 VS Code 另存为 UTF-8 with BOM。
- 直接双击 `开始监控.bat` 运行最稳：窗口不会马上消失，你能看到完整报错。

### 8.2 剪贴板被别的软件占用/保存失败

脚本已经做了防御：
- 读剪贴板异常不会崩溃
- 保存/复制会自动重试几次

仍然失败时建议：
- 换一个保存目录（不要放在被同步盘强监控的目录里）
- 临时关闭杀毒/同步软件的“实时扫描/同步”再试
